# Knowledge/Q&A Data Provenance

## Runtime Knowledge Base

| Source | Local files | Used for | Runtime role | License / usage note |
| --- | --- | --- | --- | --- |
| Curated Bucharest source registry | `data/kb_sources_bucharest.json`, `kb/clean/*.txt` | City, landmark, museum, and transport narrative facts | BM25 retrieval and extractive Q&A | Registry points to curated public sources; verify source-specific terms before redistribution. |
| Bucharest travel guidance | `data/bucharest_travel_guidance.json` | Season, budget, and visit duration guidance | Rule-based curated answers | Student-curated project data; keep broad/non-live claims. |
| TPBI GTFS feed | `kb/structured/transit.jsonl` | Routes, stops, agencies, nearby transport | Structured transport rules and text docs | Public feed from TPBI; check provider usage terms before redistribution. |
| Romania museums dataset | `kb/structured/museums.jsonl` | Museum names, addresses, descriptions, coordinates | Structured museum address/content rules and text docs | Dataset page links OGL-ROU-1.0; preserve attribution. |
| OSM/Nominatim selected places | `kb/structured/osm_places.jsonl` | Landmark addresses, coordinates, aliases | Structured place address and nearest-station rules | OSM data is under ODbL; attribution/share-alike obligations may apply. |
| Derived nearest-metro links | `kb/structured/museum_metro_links.jsonl`, `kb/structured/place_metro_links.jsonl` | Nearest metro station per place | Rule-based metro answers | Derived from local coordinates and GTFS/OSM records; inherits source obligations. |

## Thesis Note

The runtime KB is a custom, bounded Bucharest tourist-guide corpus. SQuAD is not part of the runtime KB; it is used only to motivate extractive Q&A methodology and metrics.
